# claude-skills-n-scripts

A collection of Claude skills and helper scripts.

## Contents

- **Skills**: reusable instructions that teach Claude how to handle specific tasks.
- **Scripts**: small utilities and automation helpers.

> This repo is just getting started. More skills and scripts will be added over time.

## Usage

1. Clone the repo:
   ```bash
   git clone https://github.com/HoshiyoShiro/claude-skills-n-scripts.git
   cd claude-skills-n-scripts
   ```
2. Copy or link a skill into your Claude skills directory (for example `~/.claude/skills/`).
3. Run scripts directly from the repo.
